# STM32 Boost 恒压恒流电源（课程设计）

> **一句话**：STM32F103 数字控制的 Boost 升压电源——5V 输入、12V/0.5A 输出、100kHz 开关、PI 闭环，带过压/过流/断线三重保护。
>
> 工程名 `boost-cccv-psu`（嘉立创 EDA 专业版）｜ 当前版本 **v3 重建版（2026-11-05 发板）** ｜ 状态：**已提交嘉立创加工，待收板**

| 关键指标 | 要求 | v3 重建版仿真结果 |
|---|---|---|
| 输出电压 | 12V ±5% | **+0.075%** |
| 输出纹波 | ≤5% | **1.81%** |
| 恒流精度 | 0.5A ±5% | **−0.18%** |
| 软启动过冲 | 无过冲/不触 OVP | **49mV** |
| 保护 | OVP / OCP | OVP 13.2V 锁存 / OCP **0.6A**·5ms 锁存 |
| 输入跌落 | 5V±5% | 输出偏移 **20mV** |
| 效率 | 实测 ≥75% | 预算 ~87%，**待上板实测** |

### 调试接口线序（J3/J4，接线必读）

| 口 | 用途 | pin1 | pin2 | pin3 | pin4 | 对接规则 |
|---|---|---|---|---|---|---|
| **J3** | SWD 烧录（ST-Link） | 3V3 | SWDIO | SWCLK | GND | 同名直连；杜邦线一根根接 |
| **J4** | 串口台（USB-TTL） | UART_TX | UART_RX | 3V3 | GND | **TX/RX 交叉**：板 TX → TTL 的 RX，板 RX → TTL 的 TX |

- 两个口的 GND 都在 pin4；J4 的 3V3 在 pin3（与 J3 不同），插错位置串口会不通，照上表接线即可。
- 板未上电时先接 J3 烧录，再上电；串口台随时可接。
- v3 的 J3/J4 为 2.54mm 排针**母座**（C54973823），杜邦公头直插。

## 四、固件构建

1. CubeIDE 新建 STM32F103C8T6 工程（或直接导入 `firmware/` 内的 `.ioc`）；
2. 用仓库 `firmware/Core/Src|Inc` 的 5 个文件覆盖生成的同名文件（control.c/h、bsp_power.c、main.c、cli.c）；
3. **Project → Properties → C/C++ Build → Settings → MCU Settings** 勾选 *Use float with printf from newlib-nano*（否则串口打不出电压电流）；
4. 编译烧录；串口 115200，命令 `h` 看帮助。

## 七、风险与已知取舍（报告里要写的）

1. **L1 DCR 170mΩ > 原规格 ≤80mΩ**：换 SMD 电感消除 3D 干涉的主动取舍，效率预算 89%→87%。
2. **重载瞬态跌落 1090mV**（0→0.5A 硬阶跃、6.4ms 恢复）：课程只约束稳态 ±5%，瞬态无指标。
3. **OCP 整定 0.6A**（v2 为 0.8A）：Rs1 改 0.1Ω 后 INA 输出 5V/A，0.8A 超出 3.3V ADC 量程，0.6A=1.2 倍额定，保护功能不变。
4. **U2 换 XC6206**（200mA、最大输入 6V）：负载 <60mA 裕度充足，但 **3V3 只能由 5V 口馈电**，勿接其他电源。
5. **Y1 贴片晶振负载电容 22pF（等效≈14pF < 标称 20pF）**：晶振频率略偏高几十 ppm，UART 无影响；后续若用 USB/RTC 需改 ~33pF。
6. **LED 位号为 POWER/CV/CC**（非 LED1~3）：BOM 里以 C2286 归并，位号功能对照见 08 §2.4。
7. 原理图遗留视觉项（不影响电气）：24 根零长度导线、27 个未挂 NC 的悬空脚、9 个 `$1N*` 未命名网——下一版清理。
