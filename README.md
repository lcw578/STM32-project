# STM32 Boost 恒压恒流电源（课程设计）

> **一句话**：STM32F103 数字控制的 Boost 升压电源——5V 输入、12V/0.5A 输出、100kHz 开关、PI 闭环，带过压/过流/断线三重保护。
>
> 工程名 `boost-cccv-psu`（嘉立创 EDA 专业版）｜ 当前版本 **v2 定稿（2026-11-03）** ｜ 状态：**图纸定稿，可发板**

| 关键指标 | 要求 | v2 仿真/设计结果 |
|---|---|---|
| 输出电压 | 12V ±5% | **+0.024%** |
| 输出纹波 | ≤5% | **1.3%** |
| 恒流精度 | 0.5A ±5% | **−0.33%** |
| 软启动过冲 | 无过冲/不触 OVP | **38mV** |
| 保护 | OVP / OCP | **0.2ms / 5ms 锁存** |
| 输入跌落 | 5V±5% | 输出偏移 **18.8mV** |
| 效率 | 实测 ≥75% | 预算 ~87%，**待上板实测** |

## 三、仿真复跑（5 分钟上手）

```bash
cd sim/ctrl
python - <<'EOF'
import sys; sys.path.insert(0,'.')
import plant_boost; plant_boost.RC_TAU = 8.83e3*10e-9   # v2 实装采样常数
import scenarios; scenarios.P.dcr = 0.17                # v2 电感 DCR
s={}
scenarios.S4_load_step(s, kp_v=0.06, ki_v=50.0, tag='demo', plot=True)
print(s['S4_demo'])
EOF
```

- 全部场景见 `scenarios.py`（S1~S10）与 `s8_sweep.py`（稳定域网格）。
- 控制律在 `ctrl.py`，与固件 `firmware/Core/Src/control.c` **逐行对齐**——改固件先改这里验证。
- 存档约定：结果 JSON 存 `sim/ctrl/results/`，文件名带条件（如 `summary_v2_tau88.json` = τ=88.3µs 版）。

## 四、固件构建

1. CubeIDE 新建 STM32F103C8T6 工程（或直接导入 `firmware/` 内的 `.ioc`）；
2. 用仓库 `firmware/Core/Src|Inc` 的 5 个文件覆盖生成的同名文件（control.c/h、bsp_power.c、main.c、cli.c）；
3. **Project → Properties → C/C++ Build → Settings → MCU Settings** 勾选 *Use float with printf from newlib-nano*（否则串口打不出电压电流）；
4. 编译烧录；串口 115200，命令 `h` 看帮助。

## 七、风险与已知取舍（报告里要写的）

1. **L1 DCR 170mΩ > 原规格 ≤80mΩ**：换 SMD 电感消除 3D 干涉的主动取舍，效率预算 89%→87%。
2. **重载瞬态跌落 1187mV**（0→0.5A 硬阶跃、6.5ms 恢复）：课程只约束稳态 ±5%，瞬态无指标。
3. **J3/J4 插头包络 12.7mm**：两个杜邦头不能同时插。
4. 固件未上板：全部结论是仿真级，首板按 06 §5 顺序验证。
