## 二、阻塞项（不修不能打样/上电）

### A1. PCB 板框不存在 ＋ 无安装孔 【最高优先级】
- `outline-get` 权威回读：板框对象 = 1 条 polyline、4 段、中心线包围盒 **183.8×95mil（4.7×2.4mm）**，点集 (716.7,−275)→(900.5,−275)，这不是板框。
- 器件占据 x[119,2630] y[−1445,−95] mil（≈70×39mm），但没有真正的板框线；`pcb check` 因此把板框判成 4.6×3.4mm，产生 60 条"丝印出板"警告（其中多数是失真判定）。
- v2 的 4×M3 角落安装孔在重建版中**不存在**（无 H*/M* 器件）。
- **修法**：重画 70×50mm 圆角板框（锁定），补 4×M3 安装孔；随后重跑 `pcb check` 让丝印/边缘判定恢复真实。

### A2. PCB 布线远未完成
- 全板 36 段走线 + 25 过孔（其中 **7 个是无层转换的死过孔**：VLOAD×1、$1N38/$1N40/$1N85 各 2——过孔放了但线没接上）；**0 铺铜、0 填充、0 禁布区**。
- layout-lint：**40/100 分，飞线总长 16896mil（429mm），15 处飞线交叉**。
- 官方 DRC passed=0 违规只代表"已画的铜互不打架"，不代表布通。
- v2 基线：358 轨道 + 27 过孔 + 双面 GND 铺铜 + DRC 0。
- **修法**：按 v2 工艺顺序继续——先建 POWER 网络类（见 B4）→ 功率网加宽 → 布通 → 双面 GND 铺铜 → pour-rebuild → DRC。

### A3. Rs1 = 0.1Ω，与固件电流标定不符 【功能级硬伤】
- 重建：Rs1 = 1206W4F100LT5E = **100mΩ ±1%**（1206）。
- 固件 `bsp_power.h:21`：`ADC_IOUT_GAIN 0.00032234 = 3.3/4095/(0.05×50)` —— 按 **0.05Ω** 标定。
- 后果：固件读数 = 实际电流 ×2。CC 环路会在 **0.25A** 提前进入恒流，OCP/卸载判断（UNLOAD_DROP_COUNTS 阈值 0.129A 实际对应 0.065A）全部偏移一半。
- 04 审计文档确认设计意图 Rs=0.05Ω。
- **修法（二选一）**：① Rs1 换 0.05Ω 1206（基线料 C601088）；② 保留 0.1Ω（ADC 幅度 2.5V@0.5A，信噪比其实更好）并改固件 `ADC_IOUT_GAIN=0.00016117f / ADC_IOUT_DIV=6204.7f`。**改固件则 06 号文档与仿真 ISENSE 链同步更新。**

### A4. F1 = 0Ω 电阻，保险丝保护消失
- 重建：F1 = 1206W4F0000T5E = **0Ω 跳线**；原理图上还标注"实施短路保护作用"——意图与实装矛盾。
- 04 审计 A5 的核心整改（输入唯一屏障）被回退：硬短路时 Rs1 耗散 35²×0.05=61W 先于任何东西失效。
- **修法**：F1 换回保险丝（05 文档曾用 C99555 3A/32V，或基线 BOM C41342 1206 自恢复），保持位号与网络（VIN_RAW→VIN_5V）不变。

## 三、高优先级（影响指标可信度）

### B1. 输出电容方案与仿真口径脱节
- 仿真 `plant_boost.py`：Cout=220µF 电解(ESR 0.08Ω)+10µF 陶瓷；重建 VOUT = C6+C18~C21 = **5×22µF 陶瓷**（CL31A226KAHNNNE，1206 X5R 25V）。
- 12V 偏压下 22µF X5R 实效约 11~13µF → 输出实际 ~55~65µF，ESR mΩ 级。
- 影响：S4 负载阶跃跌落 1187mV 的结论作废；LC 谐振 ~1.05kHz→~2.1kHz，陶瓷低 ESR 高 Q，**kp_v=0.06/ki_v=50 是否仍在稳定域需复跑**；稳态纹波大概率变好。
- 输入侧 5×22µF 陶瓷（C5+C14~C17）对实验室 5V 电源足够。
- **修法**：用新参数（cout≈60e-6、esr≈0.005、dcr=0.17、τ=88.3µs）复跑 S1~S8/S10，通过后更新 03§11/05/06 数字；报告口径改为"全陶瓷输出"。

### B2. 6+ 个网络丢失网名（$1N 自动名）
- $1N14=GATE、$1N198=MID、$1N3=图腾柱基极(原 PWM_B)、$1N286=NRST、$1N21=BOOT0、$1N168/$1N193=OSC_IN/OUT、$1N278=分压中点(原 VMID)、$1N289=R13-R1 节点。
- 电气正确（已随同步进入 PCB），但原理图/PCB 可读性、与 01/06 文档的对账口径退化。
- **修法**：给这些网络的旗子补网名（或把直连线改成命名旗），同步 `pcb import-changes`。

### B3. 27 个悬空脚无 NC 标记 + 23 根零长度线
- 悬空：U1.3/4/10-13/16-17/20-22/25-28/32-33/38-43/45-46（未用 GPIO，含 PB2/BOOT1）+ SW1.2/SW1.4。v2 有 28 个 NC。
- `sch check` passed=**False**，唯一 ERROR 类是 23 根零长度导线（遗留杂线）。
- **修法**：未用脚补 NC 旗（重点 PB2）；删除 23 根零长度线后重跑 check 至 passed=True。

### B4. POWER 网络类（功率线宽规则）未重建
- `net-class list`：**count=0**，GND/VIN_5V/VOUT 等全部 "Track: default"（10mil）。
- v2 建了 POWER 类 40/30/20mil 并重布功率网（Gerber 实测 1.016/0.762/0.585mm 主干）。
- **修法**：布线前重建网络类并绑定 VIN_RAW/VIN_5V/SW/VOUT/VLOAD，否则功率网会按 10mil 布出去。
